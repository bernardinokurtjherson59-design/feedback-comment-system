# Changelog

- **v1 — Basic CRUD:** Added feedback submission, listing, details, editing,
  deletion, and comments.
- **v2 — Login and roles:** Added registration, login, account roles, and
  ownership-based feedback permissions.
- **v3 — Security:** Added password hashing, prepared statements, output
  escaping, CSRF support, honeypot and time-trap checks, and IP-based lockout.
- **Live features:** Added live feedback search/status filtering and AJAX admin
  status updates with confirmation and rollback on failure.
- **Theme and menu:** Added the Charcoal & Coral theme, browser-remembered dark
  mode, responsive navigation, and the About the website popup.
